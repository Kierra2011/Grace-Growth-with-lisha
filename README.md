# Grace & Growth — Professional Edition

A polished, responsive static website for daily affirmations, Bible verses, encouragement, and gentle productivity.

## Included

- Responsive desktop/tablet/mobile design
- Professional editorial-style typography
- Light/dark mode
- Daily date display
- Random Bible verses
- Random affirmations and encouragement
- Copy-to-clipboard buttons
- Save/favorite buttons
- Clickable affirmation focus
- Daily check-in stored in the browser
- Mobile navigation
- Subtle animations
- No server or database required

## Publish with HTTPS

### GitHub Pages
1. Create a GitHub account and a new repository such as `grace-growth`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at a secure URL similar to:

`https://YOUR-USERNAME.github.io/grace-growth/`

GitHub Pages provides HTTPS automatically.

## Optional custom domain

If you later buy a domain such as `graceandgrowth.com`, you can connect it through the repository's **Settings → Pages → Custom domain** section. HTTPS can then be enabled for the custom domain.
